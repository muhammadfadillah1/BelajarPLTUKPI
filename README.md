# Pusat Belajar Pembangkit KPI

Belajar dari 6 manual operasi pembangkit (Boiler, Turbin, Elektrikal; unit 150 MW dan 380 MW): cari data, baca dokumen, peralatan & parameter, troubleshooting, kuis, dan kamus istilah.

- `index.html` : aplikasinya (1 file, jalan di browser HP/laptop)
- `dokumen/`   : PDF asli yang dibuka di dalam aplikasi

## Menu
- **Cari** — cari parameter dan data dari semua manual
- **Belajar** — baca isi manual per bab
- **Peralatan** — daftar peralatan dan spesifikasinya
- **Troubleshoot** — 114 kasus gangguan (gejala, data, penyebab, langkah, tindakan) + latihan + daftar angka SOP dengan tombol buka halaman PDF asli
- **Kuis** — soal pilihan ganda per kategori
- **Istilah** — kamus istilah teknis

Progres (poin, pangkat, lencana) tersimpan di browser masing-masing perangkat.
